4-Stage Search Pipeline (Sequential Flow)

Standard pipeline diagram. Each stage is a discrete processing unit with inputs from the previous stage and outputs to the next.

📥 Input
Raw User Query
Example: "find rice exporters in Pakistan"
STAGE 1
NLU Engine — nlu_engine.py
SetFit Intent Classifier
BAAI/bge-small-en-v1.5 backbone
GLiNER Zero-Shot NER
Product · Country · Quantity spans
KeyBERT Keyword Extractor
Stop-word stripping
Intent Branch
BUY · SELL · 9 query families
Redis 24hr Cache
NLU result memoization
OpenAI GPT-4o-mini
Fallback when low confidence
STAGE 2
Query Matcher — search_service.py
OpenSearch BM25
Fast path under 100ms
SentenceTransformer
Semantic similarity
Fuzzy Matching
Typo tolerance
SubCategory Resolution
DB lookup → ProductSubCategory IDs
Disambiguation Picker
If more than 20 variants → ask user
ORM Fallback
If OpenSearch unavailable
STAGE 3
Supplier Aggregator — aggregation.py
Trade Type Branch
BUY → sellers · SELL → buyers
Scope Filter
Pakistan vs Worldwide
Geographic Filter
Origin · Destination · Date · HS Code
ORM GROUP BY
seller or buyer name
Compute Metrics
Volume · Avg Price · Shipments · Last Date
Volume Compatibility
Post-aggregation scoring
STAGE 4
Ranking Ensemble
Heuristic Score · 70%
volume × relevance × recency
LightGBM LambdaRank · 30%
lgbm_ltr.txt model
Combine + Sort
Weighted aggregation
📤 Output
Final JSON Response
name · country · total_volume · avg_price · shipment_count · last_shipment_date

Auth, Token Economy & Subscription Sequence Flows

Standard sequence diagram with 5 lifelines. Read top-to-bottom. Each colored band is a separate flow.

👤 User
⚛️ React FE
🔧 Django API
🗄 PostgreSQL
📧 Gmail · Redis
📋 Flow A — Signup & Email Verification
1
User → React FE→ Fill signup form (email, password, name)
2
React FE → Django API→ POST /accounts/api/signup/
3
Django API → DB→ INSERT User (email_verified=False, generate UUID token)
4
Django API → Gmail→ Send verification email with 24-hour token link
5
Django API → React FE← 200 OK · "Check your email"
6
User → React FE→ Click verification link in email
7
React FE → Django API→ GET /accounts/api/verify-email/{uuid}
8
Django API → DB→ UPDATE User SET email_verified=True
9
Django API → React FE← Redirect to login page
🔑 Flow B — Login & Session
10
User → React FE→ Enter email + password
11
React FE → Django API→ POST /accounts/api/login/
12
Django API → DB→ SELECT User WHERE email=? · validate password hash
13
Django API → Redis→ Create session record
14
Django API → React FE← Set-Cookie: sessionid=...
15
React FE → User← Authenticated · redirect to dashboard
🎟 Flow C — Redeem Code · Token + Subscription Allocation
16
User → React FE→ Enter redeem code on subscriptions page
17
React FE → Django API→ POST /api/subscriptions/redeem/ {code}
18
Django API → DB→ SELECT RedeemCode WHERE code=? · check status=active and not expired
19
Django API → DB→ UPDATE RedeemCode SET status=redeemed, redeemed_by, redeemed_at
20
Django API → DB→ UPDATE User SET token_balance += plan.tokens_included
21
Django API → DB→ INSERT UserSubscription (status=active, dates, billing_cycle)
22
Django API → React FE← Success · new token balance · subscription details
🔒 Flow D — Key Contact Unlock · Costs 1 Token
23
User → React FE→ Click "Unlock Contact" button
24
React FE → Django API→ POST /api/key-contacts/{id}/unlock/
25
Django API → DB→ SELECT User · check token_balance >= 1
26
Django API → DB→ INSERT KeyContactUnlock (user, key_contact)
27
Django API → DB→ UPDATE User SET token_balance -= 1
28
Django API → React FE← Return phone, email, whatsapp details
🔑 Flow E — Password Reset
29
User → React FE→ Enter email on /forgot-password
30
React FE → Django API→ POST /accounts/api/forgot-password/
31
Django API → Gmail→ Send password reset email with token link
32
User → React FE→ Click link · enter new password on /reset-password/{token}
33
React FE → Django API→ POST with new password
34
Django API → DB→ UPDATE User SET password_hash
35
Django API → React FE← Password updated · redirect to login
